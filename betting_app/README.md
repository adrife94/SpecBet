# SpecBet — app Flutter

App Flutter multiplataforma de **SpecBet**: calculadora de decisiones de apuestas
deportivas 1X2 (comparador de cuotas, surebets, freebets y bonos), construida con
Spec-Driven Development (SDD). Es el frontend gráfico del mismo dominio que la CLI
en Python (`../bets/`): no apuesta ni obtiene cuotas, solo hace los cálculos.

## Cómo ejecutar

```
flutter pub get
flutter run
```

Objetivos disponibles: Android, iOS, web, Windows, macOS y Linux.
